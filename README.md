# Blog Lập Trình Mạng

Blog cá nhân chia sẻ về lập trình Java & JavaScript.

## Giới thiệu

Đây là blog cá nhân được xây dựng bằng Hugo với theme PaperMod, tập trung vào chia sẻ kiến thức về lập trình Java và JavaScript bằng tiếng Việt.

## Cài đặt

1. Cài đặt Hugo: https://gohugo.io/installation/
2. Clone repository này
3. Chạy lệnh `hugo server -D` để khởi động máy chủ phát triển

## Cấu trúc

- `content/`: Chứa nội dung blog
  - `posts/`: Các bài viết
  - `profile/`: Trang giới thiệu
- `static/`: Chứa tài nguyên tĩnh (hình ảnh, CSS)
- `hugo.toml`: File cấu hình Hugo

## Tính năng

- Thiết kế đẹp và tối giản
- Hỗ trợ chế độ tối/sáng
- Tối ưu hóa SEO
- Phân loại bài viết theo danh mục và thẻ
